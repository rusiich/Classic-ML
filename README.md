# 🧠 Классический машинный анализ (Classical Machine Learning)


## 🧩 Тестовые задания

| Название проекта | Описание | Используемые библиотеки |
|-------------------|-----------|--------------------------|
| **Прогноз направления движения цены акции** | Полный ML-пайплайн от загрузки и предобработки данных до обучения Random Forest, Gradient Boosting, Logistic Regression и нейронной сети. Цель — прогноз бинарного признака "рост/падение" закрытия. F1 ≈ 0.65, accuracy = 0.53. | Pandas, NumPy, Scikit-learn, Ta-Lib (ta), Statsmodels, TensorFlow (Keras), Matplotlib, Seaborn, SHAP |
